LEMANSION

Sistem Notifikasi Donasi Roblox

Panduan dan middleware lengkap untuk menyalurkan donasi real-time dari Saweria, Sociabuzz, dan BagiBagi.co langsung ke game Roblox kamu melalui Roblox Open Cloud MessagingService — lengkap dengan dashboard log donasi dan fitur donasi manual.

Masuk Dashboard Pelajari Dulu

Fitur

01

Multi Platform

Satu server menangani webhook Saweria, Sociabuzz, dan BagiBagi sekaligus, plus endpoint universal dengan deteksi platform otomatis.

02

Direct Send

Donasi diteruskan langsung ke MessagingService Roblox tanpa antrean polling, sehingga notifikasi muncul dalam hitungan detik.

03

Log Real-time

Setiap donasi tercatat lengkap dengan nama, nominal, pesan, dan status pengiriman. Log tampil langsung tanpa perlu refresh.

04

Manual Donate

Masukkan username, amount, dan message di dashboard, lalu kirim — notifikasi langsung tampil di dalam game Roblox.

05

Multi Akun

Setiap admin punya akun sendiri dan bisa login bersamaan. Donasi manual tercatat atas nama akun yang mengirim.

06

Aman

Akses dashboard dilindungi login bertoken, rate limit percobaan login, serta validasi dan sanitasi seluruh input donasi.

Cara Kerja

  1. 1

    Donatur mengirim dukungan

    Donasi masuk lewat halaman Saweria, Sociabuzz, atau BagiBagi milik kamu.

  2. 2

    Webhook diterima server

    Platform mengirim webhook ke server Lemansion, lalu datanya diseragamkan dan dicatat ke log.

  3. 3

    Diteruskan ke Roblox

    Server memublikasikan pesan ke topic MessagingService pada Universe game kamu.

  4. 4

    Notifikasi tampil di game

    Script di dalam game menerima pesan dan menampilkan notifikasi donasi ke seluruh pemain.
